### 🛡️ SecurIT — Plataforma de Segurança Industrial com IA
> Ecossistema integrado de **monitoramento de segurança do trabalho**, conformidade de EPIs, análise ergonômica e gamificação corporativa. *(repositório privado)*

| Módulo | Descrição | Stack |
| :--- | :--- | :--- |
| **Centro de Comando** | Dashboard em tempo real, mapeamento de zonas de risco, análise postural (COCO 17 keypoints) e ranking de segurança com XP | Next.js · Prisma · MongoDB · YOLOv8-Pose · DeepFace |
| **Totem de Inspeção** | Autenticação facial, detecção de EPIs com modelo YOLO customizado e sirene IoT | React · Vite · Flask · Socket.IO · ESP32 |
